How to reduce image file size without losing quality

The four levers that actually matter, in order

"Without losing quality" usually means "without losing visible quality" — every compression method technically changes data, but done right, the difference is invisible to the eye while the file gets dramatically smaller. Here's what actually controls file size, ranked by how much it matters.

1. Resize the dimensions — the biggest lever by far

A photo that's twice as wide and twice as tall has roughly four times the pixel data to store. If an image is being displayed at, say, 800px wide on a page but the original file is 4000px wide, you're storing 25x more detail than anyone will ever see. Scaling the image down to its actual display size, before any compression happens, is usually the single largest size reduction available — and because nothing beyond the original resolution was ever visible anyway, it costs nothing in perceived quality.

2. Pick a format built for photos

PNG is lossless, which sounds like a quality win, but it means PNG can't compress photographic gradients and detail nearly as well as JPG or WebP can. Converting a photo from PNG to JPG or WebP — with no other changes — commonly cuts file size by 70-90% on its own. (See JPG vs PNG vs WebP for when each format actually makes sense.)

3. Lower quality gradually, not drastically

JPG and WebP both use a quality setting, typically 1-100. Most of the visual information survives comfortably down to around 75-85% — this is usually the sweet spot where file size drops noticeably but nothing looks different at a glance. Below roughly 60-70%, compression artifacts (blocky patches, blurring around edges and text) start becoming visible, especially if someone zooms in. The mistake most people make is jumping straight to a low number instead of testing incrementally; a target file size mode that automatically finds the highest quality that still hits your size goal avoids this entirely.

4. Strip unnecessary metadata

Photos straight off a phone or camera often carry EXIF data (camera settings, GPS location, timestamps), embedded color profiles, and sometimes a thumbnail preview baked into the file. None of it affects the visible image, but it adds real, if usually small, file size — and for photos with location data, stripping it is also a privacy plus before sharing publicly.

What doesn't help as much as people assume

Re-compressing an already-compressed JPG repeatedly does reduce file size slightly each time, but it also compounds quality loss with each pass — it's not a reliable technique. It's almost always better to start from the original, uncompressed source and apply the right format, quality, and dimensions once.
