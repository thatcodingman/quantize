Frequently asked questions

Formats, target size, and what happens to your files

Do my photos get uploaded anywhere?

No. Every step — reading the file, resizing, compressing, zipping — happens locally in your browser. Nothing is ever sent to a server. See the Privacy Policy for the full explanation.

How does "target file size" mode work?

Instead of picking a quality percentage and hoping, you type in a size like "500 KB" and Quantize automatically tests different compression levels until it finds one that lands at or just under that size. It's the same manual trial-and-error you'd otherwise do by hand, just automated.

Why doesn't target size work with PNG?

PNG is a lossless format — it doesn't have a quality setting to adjust, so there's no compression level to search through. For PNG, file size depends mainly on the image's resolution and complexity. If you need a specific file size with PNG-like quality, try WebP instead, which supports both lossless and lossy modes at a much smaller size.

What's the difference between the formats?

JPG is the most universally compatible and compresses photos well, but doesn't support transparency. PNG is lossless and supports transparency, but produces larger files for photos. WebP usually gives the smallest file size for a given quality level and supports transparency, but very old software occasionally doesn't support it.

What does the "Max width" field do?

If set, any image wider than that value gets scaled down proportionally before compression. This is often the single biggest lever for reducing file size — a smaller image compresses to a much smaller file than a large one, even at the same quality setting.

Is there a limit to how many images I can process at once?

No hard limit, but very large batches or very large individual photos will take longer since everything is processed on your device rather than a server. If your browser feels sluggish with a big batch, try processing in smaller groups.

Can I download just one image instead of the whole zip?

Yes — every processed image has its own "Download" button in the file list, in addition to the "Download all" zip option.
